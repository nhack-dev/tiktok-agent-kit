# 04 TikTok（下書きを作る）

## なぜ下書きなのか
- 公式の投稿API（Content Posting API）は、アプリの審査に通るまで **非公開（自分だけ）でしか投稿できない**
- コメントへの返信の公開APIは無い
- なので、このキットは「台本・画面の文字・キャプション」を作り、**持ち主がアプリで撮って投稿** します
- 将来、持ち主が自分で審査に通したら、公式の手順（Content Posting API）で自動化できます（README に書いた条件を読んでから）

## 流れ
1. `python3 scripts/make_draft.py tiktok "（題）"` → `drafts/` に下書きができる
2. 中身を書く（`templates/tiktok.md` の欄）
   - 最初の1秒：画面の大きな文字と声で「自分のことだ」と思わせる
   - 15〜30秒で1つのことだけ
   - キャプション：1〜2行＋ハッシュタグ3〜5個
3. 持ち主に見せる → 持ち主がアプリで撮影・投稿
4. 投稿したら、持ち主に数字（再生・平均視聴・いいね・保存）を週1で聞いて `data/kata.md` へ
