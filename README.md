# TikTok エージェントキット（下書き）

あなたの AI エージェント（Claude Code など）がこのフォルダを読むと、TikTok の**台本・画面の文字・キャプションの下書き**を続けて作れるようになるキットです。投稿はあなたが TikTok アプリで行います。

**費用は、キーは要りません。かかるのは AI エージェントの利用料だけ。** このキットはほかのサーバーに何も送りません。

---

## 最初の10分

1. このフォルダを自分のパソコンに置く（受け取ったリポジトリを clone する）
2. `python3 --version` で 3.11 以上か確かめる
3. キーは要りません
4. 下書きを1本作る（ネットには何も出ない）：
   ```
   python3 scripts/make_draft.py tiktok "朝10分の家計簿"
   ```
5. できた `drafts/` のファイルを AI エージェントに埋めてもらう
6. AI エージェントに「AGENT.md を読んで、今週の下書きを3本作って」

---

## キーの取り方

キーは要りません。

**なぜ下書きなのか（公式で確かめたこと）**
- 公式の投稿API（Content Posting API）は、アプリの審査に通るまで **非公開（自分だけ）でしか投稿できない**
- コメントへの返信の公開APIは無い
- 画面の自動操作で投稿するのは規約違反やアカウント停止のおそれがあるので入れていません
- 将来、自分のアプリで審査に通したら、公式の手順で自動化できます

---

## できること・できないこと（公式ドキュメントで確かめた範囲）

| やりたいこと | できるか | 道具 |
|---|---|---|
| 台本・画面の文字・キャプションの下書き | できる | `make_draft.py`（ファイルを作るだけ） |
| 投稿 | あなたがアプリで行う | ― |
| コメント返信の自動化 | できない（公開APIなし） | ― |

## 道具

| 道具 | すること |
|---|---|
| `make_draft.py` | `templates/tiktok.md` を写して `drafts/<日付>-tiktok-<題>.md` を作る |

## 中身

```
README.md / AGENT.md / CLAUDE.md
playbooks/   01 手順 ／ 02 ふり返り
templates/   下書き・アカウントの軸・ふり返りの型
scripts/     道具（Python 3.11 の標準ライブラリだけ）
drafts/      下書きの置き場
data/        記録の置き場（git に入れない）
```

## このキットは N-Hack のAIエージェント専用です

このキットは N-Hack の受講生さん専用のプレゼントです。**N-Hack のAIエージェント
（N-Hack のプラグインを入れた Claude Code など）が、このパソコンで動いていること**を
前提にしています。

- どのスクリプトも、最初に `scripts/nhack_gate.py`（門）を通ります。門は、このパソコンに
  N-Hack のAIエージェントの「印」があるかを**読むだけ**で確かめます（ネットにつなぎません・
  何も書き換えません・プラグインには一切触れません）。
- 印が足りない環境では、スクリプトは動かずに止まります（終了コード 2）。この環境でだけ
  動くのが正しい姿です。
- いま N-Hack 環境かどうかは、次のコマンドで確かめられます。

```bash
python3 scripts/nhack_gate.py
```

N-Hack 以外のパソコンにコピーしても動きません。受講生ページ・コンサルチャンネルの案内に
沿ってご利用ください。
